# 🔍 Estudo: Consulta de Dados com Open SQL

## 📌 Conceito
O Open SQL é a linguagem padrão no ABAP para ler e manipular dados do banco de dados SAP. Funciona de forma independente do banco utilizado, o que torna os programas portáveis.

## 🎯 O que este código demonstra
- Selecionar campos específicos de uma tabela
- Filtrar registros com a cláusula WHERE
- Verificar se a consulta retornou dados (sy-subrc)
- Ordenar resultados

## 💡 Como testar este código
Acesse **abapdojo.com**, copie o arquivo `.abap` deste repositório, cole lá e clique em **Run** para ver o resultado.

## 📝 O que aprendi
- Estrutura básica do comando SELECT
- Como filtrar dados com WHERE
- O que significa sy-subrc e por que é importante
- Para que serve INTO CORRESPONDING FIELDS
